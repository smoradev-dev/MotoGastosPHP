# MotoGastos (PHP)

Sitio web sencillo en PHP para registrar los gastos de una moto. Evidencia SENA GA7-220501096-AA4-EV03.

## Cómo ejecutarlo

Opción 1 (servidor integrado de PHP):

```
cd D:\sena\MotoGastosPHP
php -S localhost:8000
```

Abrir http://localhost:8000

Opción 2 (XAMPP): copiar la carpeta en `C:\xampp\htdocs\` y abrir http://localhost/MotoGastosPHP

## Archivos

- `index.php` — lista de gastos y total
- `agregar.php` — formulario con validación
- `eliminar.php` — borra un gasto
- `acerca.php` — información del proyecto
- `includes/` — encabezado, pie y funciones
- `css/estilos.css` — estilos
- `datos/gastos.json` — datos guardados
